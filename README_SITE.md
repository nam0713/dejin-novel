# 삼류연정 작품 전용 사이트

빌드 도구 없이 실행되는 정적 작품 사이트입니다.

- 작품 소개: `index.html`, `site.js`
- 별도 본문 리더: `reader.html`, `reader.js`, `novel-content.js`
- 공통 스타일: `site.css`
- 웹 로어북: `lore.html`, `lore.css`, `lore.js`
- 디자인 조사 및 적용 근거: `DESIGN_REFERENCES.md`
- 세계관 풍경: `대진국/삼류연정/이미지/landscape.png`
- 배경음악: `music.js`, `music.css`, `assets/audio/eastminster.mp3` (Kevin MacLeod, CC BY 4.0; 출처는 `assets/audio/CREDITS.md` 및 플레이어 설정에 표시)

오른쪽 아래의 ‘음악 켜기’로 BGM을 재생합니다. 기본 음량은 20%이며 처음 방문할 때는 자동 재생하거나 음원을 미리 다운로드하지 않습니다. 같은 탭에서 페이지를 이동하면 음량과 재생 위치를 기억하며, 재생 중이었다면 이어 재생을 시도합니다. 브라우저가 자동 재생을 제한하면 버튼을 눌러 재개할 수 있습니다. 전체 페이지 이동 시 음악이 잠시 끊길 수 있습니다.

`reader.html?chapter=1`은 첫 화를, `reader.html`은 마지막으로 읽던 화를 엽니다. 본문에는 스크롤 등장 효과를 적용하지 않아 긴 화도 즉시 표시됩니다. 이전 버전의 `app.js`, `styles.css`, `site-v3.css`, `site-v3.js`~`site-v5.js`는 현재 페이지에서 사용하지 않습니다.

- 표지 및 인물 삽화: `대진국/삼류연정/이미지/`
- 본문 장면 삽화: `대진국/삼류연정/삽화/` (화당 2점, 해당 장면의 문단 뒤에 배치)
- 소설 본문: 1~3화는 기존 사이트 본문 유지, 4~20화는 `대진국/삼류연정/재집필본/그녀에게는 남편이 있었다 04~20 (재집필본).txt`
- 4~20화 삽화 배치: `chapter-illustrations.js` (원문 문단과 정확히 일치하는 위치에 삽입)
- 삽화 제작 프롬프트와 참조 이미지: `illustration-prompts.json` (내장 이미지 생성 도구, 수묵담채 스타일)
- 공통 로어북: `대진국/공통 로어북/daejin_in_lore_codex.pdf`

## 주요 기능

- 작품명과 표지를 중심으로 한 출판물 스타일의 반응형 화면
- 작품 소개에서 바로 고를 수 있는 본편 20화 차례
- 등장인물 10명 갤러리 및 확대 보기
- 대진국 로어북 독립 페이지: 권별 차례, 본문 검색
- `novel-content.js`의 화별 본문을 표시하는 독립 웹 리더
- 글자 크기, 다크 리딩 테마, 마지막 읽던 화 저장
- PC의 고정 차례와 모바일의 접이식 차례
- 모바일/태블릿/데스크톱 반응형 레이아웃

GitHub Pages를 `main / (root)` 기준으로 활성화하면 별도 빌드 없이 배포할 수 있습니다.

로컬 확인: `python -m http.server 8765 --bind 127.0.0.1` 실행 후 `http://127.0.0.1:8765/` 접속.

## 대진국 로어북

`lore.html`에서 공통 로어북을 웹 본문으로 읽습니다. 원본 PDF의 아홉 권과 서문·연표·편찬후기를 36개 항목으로 옮겼으며, 표 11개는 모바일에서 좌우로 넘겨 볼 수 있습니다. 메인 페이지와 금면수라 페이지의 ‘로어북’ 메뉴에서 이동합니다.

- 권별 바로가기: `lore.html#vol-1`부터 `#vol-9`까지. 개별 항목은 원문 쪽수에 맞춘 `#page-33` 등의 주소로 연결합니다.
- 검색은 제목과 본문을 대상으로 하며, 공백과 영문 대소문자를 구분하지 않습니다. 차례를 선택하거나 검색어를 지우면 전체 기록을 다시 표시합니다.
- JavaScript 없이도 전체 본문과 차례를 읽을 수 있습니다.
- 본문은 `lore.html`에 직접 저장합니다. 웹 본문은 사이트에서 독립적으로 관리하며 PDF로 연결하지 않습니다.
- 원본의 두 단 편집을 읽는 순서대로 옮기고 줄바꿈으로 갈라진 단어를 정리했습니다. 표지·차례는 웹 탐색 구조로 구성하고, 항목마다 한국어 제목을 덧붙였습니다.

## 금면수라 외전집

- 작품 페이지: `geummyeon.html` — 금면수라 / 천하제일인의 몇가지 이야기
- 독립 리더: `geummyeon-reader.html`, 공통 동작 `reader.js`
- 본문·삽화 위치: `geummyeon-content.js` (5화, 화당 2점)
- 표지·삽화: `assets/geummyeon/`, 생성 기록: `geummyeon-image-prompts.json`
- 원고 순서: 내게 남은 검 → 금면수라와 천살귀검 → 돌아오는 날 → 무생로 → 천하제일인의 마지막 날
- 삼류연정과 마지막으로 읽은 화를 별도 저장합니다. 글자 크기와 읽기 테마는 공통 설정입니다.
- 각 삽화는 지정 원문 문단이 나온 뒤 삽입됩니다. 원고를 고칠 때 본문 데이터와 삽화 기준 문단을 함께 갱신해야 합니다.
- 백령은 사용자 제공 인물화의 얼굴·흑의·붉은 끈을 따르되, 긴 검은 머리를 묶지 않고 풀어 내린 모습입니다.
- 최후의 도월천은 흰머리의 노인, 그를 업고 가는 인물은 중년의 진소백입니다. 진소백에게 금면 장식을 붙이지 않습니다.
