# 「그녀에게는 남편이 있었다」 교정 내역

범위: 두 텍본 제1~20화. 원본 파일과 기존 Git 작업 상태는 보존하고 별도 교정본을 작성했다. 외부 설정집은 제공되지 않았으므로 두 텍본 내부의 정합성을 기준으로 수정했다.

## 주요 판단

- 진소백의 느린 무공 성장, 서예린의 반복과 부분적인 자각, 곽문정과 진소백의 관계 변화, 십수 년 뒤 무관 후일담은 유지했다.
- 하오체·해요체·반말을 기계적으로 통일하지 않았다. 진소백이 상관에게 쓰는 존대, 동료에게 쓰는 반말, 곽문정과 가까워지며 풀리는 말투를 구분했다.
- 서예린의 “이번에는”, “말하려고 했어요”와 감나무·비녀·문·다음 발은 의도된 반복으로 남겼다. 같은 사실을 다시 설명하는 문답과 결말 총평은 축약했다.
- 월향루 출입 배경, 협곡 진입 전 정찰, 편지 심부름 아이는 인과 공백을 메우기 위해 보강한 연결 설정이다. 특히 기적에 들지 않고 월향루 별채에 드나들었다는 설정은 원문에 명시되어 있지 않았던 편집 판단이다.
- 천제·천명제·무림맹·천호위 등의 큰 세계관 설정과 후속 부를 암시하는 요소는 임의로 회수하거나 삭제하지 않았다.

## 연결 확인

| 항목 | 수정 후 흐름 |
|---|---|
| 수련 | 열세 살 시작 → 스물여덟에 십오 년 수련 → 서른 이후 이류 → 십수 년 뒤 일류 경계 |
| 기다림 | 약속 다음 날부터 예순 날 → 마흔째 지붕 수리 → 마지막 이틀 휴무 → 예순째 불참 → 다음 날 찻집 목격 |
| 정체 | 3화 이름 질문 거절 → 4화 유보 명칭 미사용 → 6화 유보 작명 → 13화 이름·금면수라 정체 확인 → 19화 곽문정에게 공개 |
| 편지 | 유자명의 편지는 7개월 이후도 포함 → 보내지 않은 초고와 새로 보낸 편지 구분 → 심윤재가 보낸 이별 편지를 예린이 수신 |
| 소품 | 스물다섯 냥 중 비급값 스물세 냥 지출 → 잔액 두 냥 → 비급 반쪽·은비녀 19화 함에 보관 |
| 계절 | 늦봄 시작 → 초여름 표행·기다림 → 여름 경과 명시 → 가을 감 수확 → 20화 십수 년 뒤 가을 |

- **본문 정리**: 회차 메모 제거.
