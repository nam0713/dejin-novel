# 플롯·호칭·말투 추가 점검

2026년 9월 29일. 현재 재집필본 1~20화를 대상으로 사건과 대사의 연결, 인물이 정보를 얻는 시점, 호칭과 어미, 회상·날짜·소품을 대조했습니다. 확인된 오류와 오해를 부르는 표현을 합쳐 24개 항목을 수정했습니다. 24개 모두가 큰 플롯 오류라는 뜻은 아니며, 작은 표현 보완도 포함합니다.

## 주요 수정

| 회차 | 확인한 문제 | 반영 내용 |
|---|---|---|
| 2~3화 | 사내가 닫힌 함에 든 돈과 곽문정 사건을 이미 알고 말하지만 정보 경로가 없음 | 주점에서 사건의 소문을 들었다는 짧은 문답을 추가. 사내 자신의 이름과 정체는 밝히지 않음 |
| 3화 | 집주인은 창운표국 사람이 왔다고 했는데 서술이 곽문정 본인으로 단정 | 곽문정이 보낸 사람이라는 진소백의 추론으로 수정 |
| 3화 | 2화에 없었던 답변을 ‘어젯밤과 같은 대답’으로 회상 | 현재의 관찰과 대답으로 수정 |
| 4화 | 반말을 제지하며 ‘말투 낮춰’라고 지시 | 뒤의 ‘말하시오’와 연결되도록 ‘말 높여’로 수정 |
| 6화 | 곽문정을 이기겠다는 선언 장소가 표국에서 술집으로 바뀜 | 실제 발언 장소와 소문이 전해진 장소를 구분 |
| 6~7화 | 날짜 표시가 아침에서 저녁으로 바뀌는 연결이 빠짐 | 하루를 보낸 뒤 표시하게 된 경위 추가. 58일째 아침에 57개인 계산 유지 |
| 7화 | 3화에서 약속한 지붕 수리가 오래 미뤄진 경위가 없음 | 진소백이 거듭 집주인을 찾아간 뒤 수리했다는 연결 추가 |
| 11화 | 오충이 갑자기 진소백에게 높임말을 쓰고 진소백은 가벼운 명령형으로 답함 | 오충의 반말과 진소백의 높임말로 조정 |
| 12화 | 곽문정이 이미 안다고 한 유자명 관련 사실을 다시 새롭게 확인 | 아직 듣지 못한 심윤재와의 약속을 묻는 대화로 수정 |
| 13화 | 금빛 가면이 있는데도 정체를 짐작할 단서가 없다고 단정 | 단서의 부재가 아니라 진소백이 소문 속 인물과 연결하지 못한 것으로 수정 |
| 13화 | 예를 갖추던 구진백이 진소백에게 갑자기 반말 | 앞뒤 대화의 예우를 유지 |
| 17화 | 집안 하녀가 주인을 외부인처럼 ‘곽 나리’로 지칭 | ‘나리께 지어드릴 여름옷’으로 조정 |
| 17화 | 월향루를 운영하는 화씨가 자신을 ‘여기 드나든’ 사람으로 표현 | 알고도 침묵했던 책임을 직접 말하는 표현으로 수정 |
| 17화 | 유자명 다음에 ‘그 전 사람들’이라 하여 알려지지 않은 앞선 연인을 암시 | ‘다른 사람들’로 수정 |
| 19화 | 전투 이틀 뒤 귀로에서 ‘아까’라고 회상 | ‘그제 산적들 만났을 때’로 수정 |
| 19화 | 이미 여러 회차 동안 자란 감이 이제 처음 열린 듯한 대사 | 이제 익어간다는 대사로 수정 |
| 20화 | 네 글자 현판을 보고 ‘두 글자’라고만 서술 | 현판 앞머리의 ‘유보’를 가리킨다고 명시 |
| 20화 | 도월천에게 쓰는 어미가 아내와의 대사로 이어짐 | 아내에게 평소 쓰는 말투로 조정 |

그 밖에 상단의 관리인이라는 직업 표현, 물동이의 손상 부위, 대사에서 확인하려는 대상, 주변 대화와 어긋나는 어미를 다듬었습니다. 정확한 수정 전후 문장은 `호칭말투점검_수정기록.json`에 있습니다.

## 호칭·말투 적용 기준

| 관계 | 유지한 기준 |
|---|---|
| 진소백 → 장형·오충 | 직장 선임과 연장자에게 높임말. 오충을 부르는 ‘오 형님’ 유지 |
| 방칠 → 진소백 | ‘형님·진 형님’과 높임말이 기본. 가까워진 뒤의 농담과 말끝 흐림은 유지 |
| 주명호 → 진소백 | ‘진 선배’와 높임말. 방칠의 ‘형님’과 구별 |
| 진소백 ↔ 사내·도월천 | 진소백은 주로 하오체, 사내는 반말. 첫 만남의 분노와 뒤의 친근한 반말을 일괄 교정하지 않음 |
| 진소백 ↔ 곽문정 | 하오체가 기본. 대립에서 술자리와 대련으로 관계가 달라지는 과정의 짧은 반말은 유지 |
| 진소백 ↔ 유자명·심윤재 | ‘유 선생·진 형·진 표사’와 하오체 중심. 공적인 첫 대면과 사적인 대화의 차이 유지 |
| 서예린 → 연인들·곽문정 | 해요체 중심. ‘윤재 공자’ 등 인물별 호칭 유지 |
| 심윤재 → 서예린 | 혼인을 알기 전의 ‘연화 소저’, 결별 편지의 ‘서 부인’ 전환 유지. 과거 회상의 ‘소저’는 오류로 처리하지 않음 |

## 유지한 서사와 검증

- 진소백은 1~12화에서 사내의 이름과 정체를 모릅니다. 13화에서 방문자의 별호 발언을 듣고 직접 이름을 물어 확인한 뒤, 서술에 도월천의 이름이 나옵니다.
- 진소백의 미련, 서예린의 반복되는 선택, 곽문정 부부의 미해결 관계를 임의로 종결하지 않았습니다. 비녀·감나무·빈방·발걸음의 반복도 서사적 기능이 있어 유지했습니다.
- 회차 20개, 회차 제목과 장면 구분을 보존했습니다. 대화 따옴표의 짝, 문자 손상, 정체 공개 순서를 확인했습니다.
- 수정본이 기록된 24개 변경만 적용한 결과와 일치하는지 대조했습니다. 최초 원본 두 파일은 변경되지 않았습니다.
