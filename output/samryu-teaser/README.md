# 삼류연정 티저 트레일러

36초, 30fps, H.264 / AAC MP4. 음악과 효과음을 포함한 수묵 모션 티저입니다. 인물이 직접 연기하는 생성 영상이 아니라, 작품 삽화·새로운 누각 그림·카메라 이동·붓질 전환·자막·입자 효과를 편집한 영상입니다.

- `삼류연정-티저-portrait.mp4`: 1080 × 1920, 9:16. 인물 중심 구도와 하단 자막.
- `삼류연정-티저-landscape.mp4`: 1920 × 1080, 16:9. 공간과 한지 여백을 살린 별도 구도.
- `watch.html`: 두 버전을 볼 수 있는 로컬 미리보기.
- `storyboard-portrait.jpg`, `storyboard-landscape.jpg`: 편집 구성을 한눈에 보는 참고 이미지.

## 구성

| 구간 | 장면 / 자막 |
|---|---|
| 0–4.4초 | 비 내리는 누각. 스물여덟, 삼류 표사 진소백. |
| 4.4–8.8초 | 은비녀를 건네는 청혼. |
| 8.8–14초 | 그녀에게는 남편이 있었다. |
| 14–18.4초 | 사람마다 때가 있는 거다. |
| 18.4–23.4초 | 수련과 패배. 나는 남들보다… |
| 23.4–26.4초 | 아이를 구하는 진소백. 늦을 뿐이야. |
| 26.4–36초 | 붓글씨 제목, 한 사람의 강호. |

새로 만든 누각 그림은 내장 이미지 생성 도구를 사용했습니다. 사용자의 피드백에 따라 촘촘한 미세 질감과 잔디테일을 줄이고 넓은 먹선·담채 면으로 다시 그렸습니다. 최종 소스는 `source/rain-pavilion-brush.png`이며 제작·수정 프롬프트도 같은 폴더에 있습니다. 기존 삽화 파일과 사이트는 수정하지 않았습니다.

## 재편집

`render_teaser.py`와 `source/`에 재현 가능한 편집 소스를 보관했습니다. 필요한 패키지는 Pillow, NumPy, OpenCV, SciPy, imageio-ffmpeg입니다. 두 영상은 별도 구도로 렌더링하며 단순 회전·레터박스 변환을 사용하지 않습니다.
